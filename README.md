# 单网关 IPv6 地址池换池演练（Flask + SQLite）

模拟单网关一次 IPv6 委派前缀池更换的值班演练。SQLite 持久化**模拟时钟、地址池、租约、
空闲区间、撤路发布、网关路由表与路由条目限额**，内置旧池及其租约；网页录入已上线的
新池 CIDR 与委派长度（/56 或 /60），新池须与旧池**不相交**，配置无效则整单回滚、保留原状。

## 进程划分

| 进程 | 端口 | 职责 | 数据库打开方式 |
|---|---|---|---|
| `web`（值班台，写入端） | 8000 | 换池、领址、模拟时钟两阶段推进、撤路数据发布、路由限额设置与用量查看 | 读写（WAL，单写者 gunicorn 1 worker） |
| `gateway`（网关，独立进程） | 8001 | 只读查询撤路发布；网页/JSON 探测目的 IPv6 地址在**已提交路由**中的命中前缀或丢弃 | `mode=ro` 只读 URI |

两容器共享命名卷 `drill-data` 上的同一个 SQLite 文件；WAL 允许网关在写入期间并发读。

## 启动

```bash
docker compose up --build
# 值班台：       http://localhost:8000/
# 网关路由探测页：http://localhost:8001/
# 网关撤路视图：  http://localhost:8001/withdrawal
```

无 Docker 时本地运行（需要 Python 3.11，`pip install -r requirements.txt`）：

```bash
export DRILL_DB=/tmp/pool_drill.db
gunicorn --workers 1 --threads 8 -b 0.0.0.0:8000 "app.web:create_app" &
gunicorn --workers 1 --threads 4 -b 0.0.0.0:8001 "app.gateway:create_app" &
```

## 内置数据（模拟时钟 t=0 起，单位秒）

- 旧池 `2001:db8:aaaa::/48`，委派 `/60`，共 4096 个槽位。
- 旧租约：slot 0/1 到期 3600，slot 2/5 到期 7200，slot 6 到期 10800；
  slot 4 的租约在演练开始前已到期（演示历史到期数据）。
- 旧池初始空闲区间 `[3,5)`、`[7,4096)`（半开区间，按槽位编号）。

## 关键规则与实现位置

1. **换池校验，无效保留原状**：`app/common.py::validate_pool` 严格 CIDR 解析（拒绝主机位、
   非 IPv6），委派长度仅允许 56/60 且不得短于池前缀；`app/logic.py::change_pool` 另要求
   **新池与旧池不相交**（`overlaps`，含互相包含），在 `BEGIN IMMEDIATE` 事务内先全部校验
   再写入，任何异常都 ROLLBACK。单次演练只允许换一次。
2. **换池后仅从新池发放 60 分钟租约，避开未到期前缀，池满提示**：`meta.new_pool_id` 切换
   活动池；可分配空间来自持久化的 `free_intervals`（半开 `[start,end)` 槽位区间），
   first-fit 只取首区间首槽，池满（无空闲行）返回 400 且不写入。
3. **旧租约按原期限到期**：到期时刻在建租约时固定写入 `expires_at`，时钟推进不修改未到期租约。
4. **网关路由表 = 新池在租地址的最少 CIDR 覆盖，增量维护**（`app/logic.py` 路由表段）：
   - `routes` 表只存已提交条目；覆盖恰好等于新池在租槽位集合，不含空闲地址；
     条目两两不可再合并（buddy 对齐），因此是**唯一最简**覆盖；
   - 领址时 `_route_add_slot` 插入单槽块后逐层 buddy 合并，每步一次索引点查；
   - 时钟提交时 `_route_remove_slot` 把覆盖到期槽位的条目逐层对半拆分，只保留仍在租的一半；
   - 两者开销都是 O(log 池规模)，**不逐槽展开地址池，不回扫未变租约或整张路由表**；
   - `route_state.entry_count` 是随同事务维护的运行计数器，限额核对与用量展示都读它，
     不做 `COUNT(*)` 全表扫描。
5. **路由条目限额：值班台设置与查看，超限整单回滚**：
   - `POST /api/route-limit`（`limit` 留空 = 不限）；**低于当前用量的限额不生效**，
     原限额保持不变；
   - 领址与时钟提交都以**整批变更后**的条目数为准核对限额；超限则整单 ROLLBACK，
     **保留原时钟、租约与路由**，错误提示中给出所需条目数；
   - 时钟提交超限后推进保持待提交：提高限额可重试提交，或手动退回。
6. **网关探测只按已提交路由，读取数不随表项增长**：`GET /probe?address=…` 与网关首页
   网页做最长前缀匹配——按新池前缀长度范围（/48→/60 至多 13 级）逐级索引点查，
   探测读取的路由记录数与表项总数无关；网关连接只读，永远只看到已提交状态。
7. **网关独立进程只读查撤路**：`GET /withdrawal` 返回发布行中的最早安全撤路时刻，以及
   有效（active）且委派前缀不被新池 CIDR 完整包含（`subnet_of`）的旧租约清单；
   全部旧租约到期后最早撤路时刻为 `null`（可立即撤）。
8. **模拟时钟两阶段推进，只核算本次到期租约，暂停期间照常服务**：
   - `POST /api/advance` 暂停：快照 `expires_at <= 目标时刻` 的 active 租约 id 集合与最大租约 id，
     写入 `clock_advance(pending)`，**不改动时钟与租约**；
   - 暂停期间领址与网关查撤路/探测均正常；
   - `POST /api/advance/commit`：在一个事务内重新计算到期集合——
     - 暂停期间新领且在本次到期的租约自动进入集合并计入（响应字段 `added`）；
     - 若快照中应有成员从当前到期集合消失（名单变化），返回 **409 退回重做**，
       原时钟与已领租约全部保留；
     - 提交成功则同一事务内完成：租约置 expired、槽位释放并归并空闲区间、**路由增量拆分**、
       时钟前进、撤路结论重新发布；
   - `POST /api/advance/abort` 手动退回；重启时启动恢复（`db.recover_pending`）把崩溃遗留的
     pending 行标记 aborted，两端按同一已提交状态继续。
9. **提交中断原子性**：提交接口支持 `fault_inject` 演练——在 COMMIT 前关闭连接模拟进程丢失，
   SQLite 自动丢弃未提交事务；重启恢复后时钟、可领范围、撤路发布与路由表仍为上一个已提交状态。
10. **不展开候选前缀、重启/首笔领址不回扫在租明细、找空位开销不随连续占用段增长**：
    - 新池只写一行覆盖整池的空闲区间，前缀文本由整数运算 `slot_prefix` 现算，绝不枚举；
    - 空闲区间持久化在表中，重启直接读取，无任何租约扫描重建；
    - 分配只查 `ORDER BY start_slot LIMIT 1` 的首空闲行，开销取决于空闲碎片数，
      与连续占用段内的租约数量无关（自测 500 连占后实测约 17ms）。
11. **沿用原卷升级**：`init_db` 对旧版本卷一次性迁移——补建 `route_state` 行，并按
    **持久化空闲区间的补集**（在租槽位 = 池空间减去空闲空间）重建新池已生效路由，
    不回扫租约、不逐槽展开；重启后限额与已生效路由原样保留。

## HTTP API（均支持 JSON；表单提交后 302 回值班台）

| 方法 路径 | 说明 |
|---|---|
| `POST /api/pool` | `{cidr, deleg_len}` 新池上线（须与旧池不相交） |
| `POST /api/lease` | `{count}` 从活动池发放 60 分钟租约 |
| `POST /api/route-limit` | `{limit}` 设置路由条目上限（留空清除）；低于当前用量不生效 |
| `GET  /api/routes` | 路由用量、限额与前 50 条已提交条目 |
| `POST /api/advance` | `{target_seconds}` 暂停并核算本次到期 |
| `POST /api/advance/commit` | 提交（可带 `{"fault_inject": true}` 演练中断） |
| `POST /api/advance/abort` | 退回重做 |
| `GET  /withdrawal`（网关 8001） | 最早撤路时刻 + 未覆盖有效旧租约 |
| `GET  /`（网关 8001） | 探测网页：输入目的 IPv6，显示命中前缀或丢弃 |
| `GET  /probe?address=…`（网关 8001） | JSON 探测：`action=hit/drop`、`prefix`、`route_lookups` |
